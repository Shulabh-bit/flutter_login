# Nexa – Flutter Login & Registration UI

A clean, responsive Login and Registration interface built with Flutter as part of a Flutter lab assignment. It demonstrates widgets, layouts, text fields, buttons, navigation and basic form validation.

## Features

- Login page with app logo and name
- Email / Username and Password fields
- Show / Hide password toggle
- "Forgot Password?" option
- Link to navigate to the Registration page
- Registration page with Full Name, Email, Password and Confirm Password fields
- Show / Hide toggle on both password fields
- Create Account button
- Link to navigate back to the Login page
- Form validation:
  - Required fields cannot be empty
  - Email format check
  - Password must be at least 6 characters
  - Confirm Password must match Password

## How to Run the Project

1. Make sure Flutter is installed:
```bash
   flutter doctor
```
2. Clone the repository:
```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
```
3. Go into the project folder:
```bash
   cd <your-repo-name>
```
4. Install dependencies:
```bash
   flutter pub get
```
5. Run the app on an emulator or connected device:
```bash
   flutter run
```
